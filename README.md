# WooCommerce Importador Estoque & Preços

Plugin de WordPress (v2.1) que atualiza **estoque** (a partir de um serviço intermediário ligado ao Sankhya) e **preços** (via Precode) dos produtos do WooCommerce.

- Páginas de administração para configurar a origem e testar um produto (`includes/admin-pages.php`, ação AJAX de teste).
- Funções separadas para preço, imagem, ficha técnica e visibilidade (`includes/*-functions.php`).
- Configuração por opções do WordPress (URL e token do serviço); o plugin avisa quando a integração está habilitada sem configuração.
- Deploy via plugin Git Updater.
